Como usar o tour

  1. 👆
    Olhar em volta
    Arraste a tela com o dedo ou o mouse.
  2. ▲
    Andar
    Toque no botão azul ▲ ou dê dois toques no chão, na direção desejada.
  3. ⓘ
    Ver uma loja
    Toque no letreiro (o selo amarelo i) para ver telefone, WhatsApp e detalhes.
  4. 🔍
    Achar uma loja
    Use Buscar loja: o tour leva você até ela. O mapa no canto mostra onde você está.
